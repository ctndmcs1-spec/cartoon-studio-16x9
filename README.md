# 🎙️ TTS + Voice Cloning

Tool chuyển văn bản thành giọng nói với **cảm xúc** và **sao chép giọng nói** từ 10 giây ghi âm.

## ✨ Tính năng

- 🔊 **Giọng có sẵn** — 8+ giọng Neural của Microsoft Edge (Việt, Anh, Trung, Nhật, Hàn)
- 🎭 **9 preset cảm xúc** — Vui, Buồn, Hào hứng, Truyền cảm, Kể chuyện, Thì thầm, Tin tức...
- 🎤 **Voice Cloning** — Ghi âm 10 giây → lưu thành profile → tái sử dụng mãi mãi
- 📝 **Xuất SRT** — Tự sinh phụ đề từ timestamp của Edge TTS
- 📄 **Đọc từ file** — Upload PDF / DOCX / TXT để lấy nội dung
- 🧹 **Chống vấp** — Tự làm sạch văn bản, chia câu dài
- ⬇️ **Tải MP3 / WAV / SRT**
